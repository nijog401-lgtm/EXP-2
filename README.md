This SQL program creates a Marksheet table to store students' marks.
- The Marksheet table contains the student's name, roll number, and marks for three subjects: ACD, DSD, and CAO.
- VARCHAR is used for the student's name, while INT is used for the roll number and marks.
- The INSERT INTO command is used to add four students' records to the table.
- Each student has a unique roll number along with their marks in the three subjects.
